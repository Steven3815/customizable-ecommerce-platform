## Project Overview

This project provides a customizable e-commerce platform
designed for small businesses to build their own online presence.

The system supports both:
- Shopping mode: customers can browse products, add items to cart, place orders, and complete purchases.
- Showcase mode: businesses can create a product display website without enabling shopping and order functions.

The platform includes product management, shopping cart,
order processing, store customization, and administration features.

## Features

### User

- Product browsing
- Product category navigation
- Search products
- Shopping cart
- Order checkout
- Order tracking
- Customer service

### Admin

- Product management
- Category management
- Homepage customization
- Banner management
- Order management
- Payment management

### Future Improvements

- AI customer service
- Membership points system
- Multiple website templates
- AWS cloud deployment
